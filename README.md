# Landing Page da Psicóloga

## Descrição
Esta é uma landing page projetada para uma psicóloga, com o objetivo de apresentar seus serviços e facilitar o contato com potenciais clientes. A página é intuitiva e oferece informações sobre as áreas de atuação da psicóloga, além de permitir que os visitantes agendem consultas de forma prática.

## Instalação
Para instalar e executar o projeto, siga estas etapas:
1. Clone o repositório: `git clone <URL do repositório>`
2. Navegue até o diretório do projeto: `cd lp-psi-kelly`
3. Instale as dependências: `npm install`

## Uso
Para acessar a landing page, inicie o servidor de desenvolvimento com `ng serve` e acesse `http://localhost:4200/`.
